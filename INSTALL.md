# Сборка и установка ChromeFinder

## 1. Что понадобится

- **Android Studio** (последняя версия) — самый простой путь, либо
- **JDK 17** + командный Gradle, если собираешь из терминала.
- Телефон на **Android 8.0+** с установленным **Google Chrome**.

## 2. Первый запуск (генерация Gradle-обёртки)

В репозитории нет бинарного `gradle/wrapper/gradle-wrapper.jar` (его нельзя
хранить как текст). Сгенерируй его один раз:

- **Через Android Studio:** просто открой папку проекта — IDE сама докачает
  Gradle и создаст обёртку. Дальше собирай кнопкой ▶.
- **Через терминал** (нужен установленный Gradle):
  ```sh
  gradle wrapper --gradle-version 8.9
  ```

## 3. Сборка APK

```sh
./gradlew assembleDebug
```

Готовый файл появится здесь:
```
app/build/outputs/apk/debug/app-debug.apk
```

## 4. Установка на телефон

Подключи телефон по USB с включённой отладкой и:
```sh
./gradlew installDebug
# или вручную:
adb install app/build/outputs/apk/debug/app-debug.apk
```
Либо просто перекинь `app-debug.apk` на телефон и открой его (разреши
установку из неизвестных источников).

## 5. Включить службу спец. возможностей (обязательно!)

Без этого приложение не сможет читать страницу.

1. Открой приложение **ChromeFinder**.
2. Если вверху горит баннер — нажми **«Открыть настройки спец. возможностей»**
   (или вручную: Настройки → Спец. возможности → ChromeFinder).
3. Включи переключатель и подтверди.
4. Вернись в приложение — баннер пропадёт.

> Android предупредит, что служба «может читать содержимое экрана». Это
> ожидаемо: именно так приложение читает открытую в Chrome страницу. Данные
> никуда не отправляются — поиск идёт прямо на телефоне.

## 6. Как пользоваться

1. Введи **адрес сайта** (можно без `https://`).
2. Введи **что искать** и выбери режим:
   - **Содержит** — простое вхождение слова/фразы;
   - **Регулярка** — поиск по регулярному выражению.
3. Нажми **«Запустить»** — откроется Chrome, страница загрузится, приложение
   прочитает её (при необходимости прокрутит) и покажет найденные фрагменты.
4. Вернись в ChromeFinder, чтобы увидеть результат.

## 7. Если что-то не работает

| Симптом | Причина / решение |
|---------|-------------------|
| «Google Chrome не установлен» | Поставь Chrome из Play Store. |
| Ничего не находит | Проверь, что текст реально есть на странице (не картинка); попробуй режим «Содержит». |
| Баннер не пропадает | Служба не включена — повтори шаг 5. |
| Сразу пишет «ничего не найдено» | Страница ещё грузилась — нажми «Запустить» повторно. |

Логи для отладки: `adb logcat -s BrowserAutomation ChromeLauncher`.
